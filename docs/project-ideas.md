# Pet Project Ideas

A shortlist of candidate pet projects. **We are starting with #1 — Second Opinion.**

## 1. Second Opinion — a decision-making arena ⭐ (starting here)

You pose a real decision (e.g. "should I take this job?", "React vs. Svelte for X?")
and the app spins up 3–4 distinct AI personas that argue *different* positions, then a
judge synthesizes a recommendation. You watch the debate unfold.

**Why it's cool:** multi-agent orchestration where the disagreement is the point. Lots of
design space — persona tuning, debate formats, source citations, scoring rounds. Genuinely
useful output and a striking UI opportunity (split-screen debate, live streaming).

**Core hard problem:** multi-agent consensus / orchestration.

## 2. Time Machine — a personal life-in-data dashboard

Pull your own digital exhaust — Git commits, Spotify history, screen time, location history,
bank exports — into one timeline you can scroll and query in plain English
("what was I working on the week I listened to the most music?").

**Why it's cool:** the data is personal and instantly meaningful. Scales from one source and a
bar chart up to a queryable personal knowledge graph. Good for data pipelines, embeddings /
semantic search, and visualization.

**Core hard problem:** data integration.

## 3. Dungeon Master — a procedural text adventure that never repeats

An AI-driven RPG where the world, NPCs, and quests are generated on the fly and *persist*.
The hard twist: state consistency — the blacksmith remembers you stole his hammer three
sessions ago.

**Why it's cool:** a real engineering problem disguised as a game — state management, memory /
context windows, save systems, world-map generation. Endlessly demoable.

**Core hard problem:** persistent state.
